# Project MRI — provenance and public boundary

- **Created and designed by:** Lua Helena Moon Martins Cardoso (Moon).
- **AI-assisted coauthorial development:** Áurion.
- **Reference build:** Project MRI v0.3.0, prepared for InfraJam 2026’s Open Source track.
- **Canonical repository:** <https://github.com/luahelenammc/Project-MRI>.
- **Corpus:** synthetic fixtures created for demonstration and testing.
- **Method lineage:** a bounded, public-safe derived implementation of Moon Source context-governance principles.
- **Mutation policy:** findings and repair plans are proposals; the reference build never rewrites source files.
- **Provider policy:** no live provider, GPU or external model integration is claimed.

The public package deliberately excludes hospital, patient, employee, collaborator, private Moon Professional Source, Local Moon Source, Lunar Citadel and connector data. It also excludes secret prompts, credentials and private heuristics.

The project is understandable without learning MSL or private Moon vocabulary. Its public value is the executable boundary and evidence model, not exposure of the private corpus from which the broader method evolved.

## Standalone migration

The first public competition build was temporarily hosted at `luahelenammc/Moon-Source/projects/project-mri` because the available execution connector could not create a standalone GitHub repository. After Moon created [`luahelenammc/Project-MRI`](https://github.com/luahelenammc/Project-MRI), the verified implementation was imported here as its canonical home.
